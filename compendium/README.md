# The Harvest Compendium

This folder contains the project-specific compendium for The Harvest — aligning this codebase to ACT's master philosophy, linked stories, and operational practices.

## Structure

```
compendium/
├── README.md              ← You are here
├── identity.md            ← Project identity, philosophy alignment, LCAA
├── stories/
│   └── index.md           ← Storytelling opportunities (no vignettes yet)
├── operations/
│   ├── authority.md       ← Authority check, consent, handover
│   └── partners.md        ← Key partnerships
└── roadmap.md             ← 2026 focus and current status
```

## How to Use

- **New contributor?** Start with `identity.md`
- **Building a feature?** Check `operations/authority.md`
- **Looking for stories?** See `stories/index.md` for priorities
