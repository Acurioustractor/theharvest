# The Harvest SOP pack

Plain-language standard operating procedures for running the place. Each one is written so a first-week steward can follow it alone. Short steps, plain words. Where a detail is not decided yet, the SOP says so with a `[DECIDE: ...]` note. Do not guess past one.

## Four screens plus paper (the whole system)

1. **GHL / LeadConnector** holds the relationships (people, notes, tags, the pipelines).
2. **Square POS** is the till for the shop shelf (sales, stock, maker payouts).
3. **Humanitix** runs events and tickets (the gate check-in too).
4. **WhatsApp** carries the crews (the day-to-day talking surface).
5. **Paper** is the room (the come-back sheet, the kraft labels, the rosters on the wall). The rest is warmth.
