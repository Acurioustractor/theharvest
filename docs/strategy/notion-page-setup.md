## Key Notion Features to Use

1. **Database for Tasks** — link to master ACT task database
2. **Timeline View** — for project milestones (10-week path, post-commencement quarters)
3. **Board View** — for task status (To Do / In Progress / Done)
4. **Calendar View** — for events and markets
5. **Rollups** — aggregate financials from sub-pages
6. **Relations** — link to ACT Farm, Empathy Ledger, other ACT projects
