# The Harvest opening weekend, Saturday 20 June 2026

This folder holds the working papers for the opening weekend at The Harvest, Witta, on Jinibara Country. It is for the people running the day: Ben, Nic, Susie, and whoever holds a role on the gate, the garden walk, the pizza bar, or the long table. Each file does one job, so you can pick up the part you need and not read the whole set. Plain over polished. Only say what is true today.

The gate opens this Saturday at 1pm, with pizza from 5pm, and the day runs till dark. Come see what is taking shape. Kids welcome.

## What is in here

| File | What it is |
|---|---|
| `00-overview.md` | The one-page map of the weekend: the north star, the shape of Friday to Sunday, the arc of Saturday, who holds what, the one gate that can stop the day, and a link to every file here. |
| `01-maker-morning.md` | Run sheet for the private maker session before the public gate, 10:30 to 12:45. Invite only, never broadcast, Nic leads it on site. |
| `02-open-afternoon.md` | Run sheet for the public open afternoon from 1pm: the shape of the day, the role roster, and the open, serve and close checklist. |
| `03-pizza-evening.md` | Run sheet for the evening from 5pm: make-your-own pizza on three doughs, oven and fire safety, the one conversation about what happens next, and the close after dark. |
| `04-branding-and-signage-pack.md` | The print-and-place layer. The brand look and the full signage list, one sign per row, ready to make and place by the morning. |
| `05-community-ideas.md` | The warmth layer. Every experience idea pulled from the three moments, deduped, plus the cross-cutting ones nobody owns yet: welcome, accessibility, the Green Harvest story, capturing memory with consent, and hearing the quiet people. |
| `06-readiness-gates-and-roles.md` | The one print-and-pin page for the small team: the open gates that can stop the day (owner, by-when, status, fallback) and the day-of roster across all three moments. |
| `07-friday-prep-and-sunday-reconcile.md` | The two bookend jobs: getting ready on Friday and reconciling on Sunday. Points to the canonical run sheets and holds the Friday checklist. |

## Start here

1. Read `00-overview.md` first for the shape of the whole weekend.
2. Then read the three moment files in order: `01-maker-morning.md`, `02-open-afternoon.md`, and `03-pizza-evening.md`.
3. When it is time to make signs and brief the team, print from `04-branding-and-signage-pack.md` and `06-readiness-gates-and-roles.md`.
4. Run `07-friday-prep-and-sunday-reconcile.md` on Friday to set up, and again on Sunday to reconcile.

## A few things to hold

- **Members hear first.** Members hear the date before the public does. Do not push 20 June into wider public copy ahead of that.
- **No em-dashes.** Use a full stop, or "and", or a comma. Keep the voice plain and warm, like a real person from the hills, not a brochure.
- **Only say what is true today.** No invented turnout, no past-tense build claims, no prices on the day. Nothing is sold on 20 June.
