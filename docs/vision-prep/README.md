# Vision Prep — Grant Presentation

Working folder for preparing The Harvest vision pitch to Grant (landlord).
Target: `/vision` page on the website.

## Folder Structure

```
vision-prep/
  content/          ← Copy, notes, section drafts, context docs
  audio-transcripts/ ← Conversation recordings → transcriptions
  images/           ← Photos, sketches, architect drawings, before/after shots
```

## Audio Transcripts

Drop audio files (mp3, m4a, wav) into `audio-transcripts/`.
Transcriptions will be saved alongside as `.md` files with the same name.

## How Content Feeds the Vision Page

| Folder | Feeds Into |
|--------|-----------|
| `content/` | All sections — copy, financials, talking points |
| `audio-transcripts/` | Key quotes, decisions, context for any section |
| `images/` | The Space section (before/after, floor plans, sketches) |
