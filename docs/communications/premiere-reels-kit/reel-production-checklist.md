# Reel Production Checklist

## Before Editing

- Choose one purpose: place, people, progress, event, or invitation.
- Pick one channel goal: reach, replies, RSVPs, volunteers, or newsletter signups.
- Choose one primary clip that can hold the first 2 seconds.
- Keep the finished video under 90 seconds.
- Use vertical footage where possible.

## Edit

- Put the strongest visual first.
- Cut dead space from the start of every clip.
- Keep captions short and readable.
- Keep key text inside the safe zone.
- Use natural sound when it adds life.
- Keep music quiet under voice.
- Add a simple end question or invitation.

## Text Overlay Rules

Good:

```text
What should this room hold?
```

```text
The nursery is already the heart.
```

```text
Working bee this Saturday.
```

Avoid:

```text
Long paragraphs on screen that people cannot read before the clip changes.
```

## Export Check

- MP4
- H.264
- 1080 x 1920
- 30 fps
- AAC audio
- under 300 MB
- under 90 seconds
- file opens locally before upload

## GHL Check

- Upload video to GHL.
- Preview Facebook.
- Preview Instagram.
- Check thumbnail.
- Check caption line breaks.
- Check date and time.
- Publish or schedule.
- Pull the record back to Notion.
