# Empathy Ledger Media Intake

Use this before building posts in GHL.

The point is to stop choosing from loose files. Empathy Ledger becomes the place where photos, drone, video, and story fragments are held with enough context to reuse.

## Weekly Flow

```text
1. Collect media folders
2. Edit and rate in Lightroom
3. Export only useful selects
4. Add selects to Empathy Ledger
5. Tag by work, theme, and stage
6. Choose the week's strongest sets
7. Draft copy and reels from those sets
8. Build and schedule in GHL
9. Record final posts in Notion
```

## Story-To-Website Flow

Use this when a person, transcript, and media set should become a real article.

```text
1. Create or confirm the storyteller in Empathy Ledger
2. Tag photos where the person appears
3. Link those photos as appears_in, consent pending, hidden from public
4. Find the transcript and source video
5. Create a private EL source story
6. Create or publish an EL article syndicated to harvest
7. Check the Harvest article URL
8. Create a GHL draft social post that links to the article
9. Use the same transcript and source video for a future reel cut
```

For video:

```text
source video in EL -> choose 20 to 45 second story section -> cut 1080x1920 -> use Sophie audio as spine -> add minimal overlay only if needed -> upload final MP4 to GHL Media Storage -> publish as Reel
```

## Lightroom Process

Do not export everything into the working folder.

Use this simple pass:

| Lightroom rating | Meaning | What happens |
| --- | --- | --- |
| 1 star | Keep for archive | stays in Lightroom only |
| 3 stars | Useful story asset | export to `EL selects` |
| 5 stars | Hero / post candidate | export to `EL selects` and mark `featured` in EL |
| Reject | Duplicate, soft, bad face, nothing useful | do not export |

Use color labels if that feels faster:

| Label | Use |
| --- | --- |
| Green | Garden / Sophie |
| Blue | Milk crate pavilion |
| Purple | Drone / wide site |
| Yellow | Details / textures |
| Red | Needs permission before public use |

The important folder is `EL Selects`.

That is the folder I should look at first. It should contain the edited, useful photos only.

## Export Settings

For Empathy Ledger:

```text
Format: JPG
Color: sRGB
Long edge: 2400px to 3000px
Quality: 80 to 90
Filename: YYYYMMDD-harvest-story-shortname-sequence.jpg
```

For GHL/social final posts:

```text
Square/carousel: 1080x1080 or 1350x1080
Story/reel still: 1080x1920
Quality: 85 to 90
```

Keep big originals in Lightroom. EL gets the reusable working version. GHL gets the final publishing version.

## Intake Batches

Use batches, not one giant dump.

| Batch | What goes in | Main tags |
| --- | --- | --- |
| Sophie story | Sophie photos, garden detail, people tending beds | `the-garden`, `grow`, `gather`, `during` |
| Drone progress | Aerial stills and source drone videos | `milk-crate-pavilion`, `make`, `gather`, `milestone` |
| Milk crate pavilion | Crate delivery, structure, closeups, people building | `milk-crate-pavilion`, `make`, `gather`, `during` |
| WhatsApp harvest | Exported chat images and videos worth keeping | match the work, usually `the-garden` or `milk-crate-pavilion` |

## Minimum Metadata

Every useful asset needs:

- clear title
- short alt text
- work tag
- theme tag
- category tag
- whether it is safe for public use

Good defaults:

```text
milk-crate-pavilion + make + gather + during
the-garden + grow + gather + during
general-harvest + gather + milestone
```

## What Becomes A Post

Choose assets that do one job:

- show visible progress
- make a practical local ask
- make the work feel human
- explain one piece of the place
- set up the next working bee or newsletter

Do not post a whole dump. One post needs one job.
