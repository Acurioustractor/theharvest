# Weekend Debrief To Content

This is the weekly talking loop.

Ben talks through what happened. The agent turns it into usable posts, reel edits, captions, and next-week patterns.

## The Simple Flow

```text
Ben voice dump -> agent extracts stories -> content slate -> edit briefs -> GHL posts -> Notion record
```

GHL stays the publishing desk.

Notion stays the record.

Premiere stays the video bench.

## How Ben Should Start

Use this exact prompt after a weekend:

```text
Weekend debrief.

Here is what happened:

[Talk messy. Names, moments, funny bits, what got done, what surprised you, who showed up, what still feels unclear.]

Photos and videos I have:

[List clips or describe what is on the phone.]

WhatsApp notes:

[Paste useful messages, voice note transcripts, media descriptions, and permission status.]

What we need next:

[Materials, people, event RSVPs, newsletter signups, comments, ideas, help.]

What I am unsure about:

[Anything awkward, sensitive, unfinished, or not ready to say publicly.]
```

Messy is fine. The point is to get the real signal out before it gets polished to death.

## What The Agent Should Listen For

Pull out:

- one human moment
- one place detail
- one practical thing that changed
- one unresolved question
- one useful ask
- one thing not to say publicly yet
- one possible reel
- one possible Facebook post
- one possible Instagram post
- one possible newsletter note
- any WhatsApp item that needs permission before public use

## First Response Shape

The agent should respond like this:

```text
The center of the week is: [one sentence]

What happened:
- [fact]
- [fact]
- [fact]

What it means:
- [interpretation]
- [interpretation]

What to publish:
1. [Post title] - [channel] - [job]
2. [Post title] - [channel] - [job]
3. [Post title] - [channel] - [job]

Video to make first:
[one reel recommendation]

One thing to avoid:
[risk, overclaim, sensitivity, or boring angle]
```

Keep it short. Then build the drafts.

## Repeatable Weekend Patterns

### Pattern 1: The Place Changed

Use when something physical moved, cleared, opened, arrived, or became visible.

Post types:

- before and after reel
- Facebook progress note
- Instagram place note

Opening lines:

```text
One corner changed this weekend.
```

```text
The place made a bit more sense after this.
```

```text
Small progress, but the useful kind.
```

### Pattern 2: Someone Showed Up

Use when a person, neighbour, maker, grower, kid, volunteer, or friend brought energy.

Post types:

- human story
- thank you post
- newsletter note

Opening lines:

```text
The best part was who showed up.
```

```text
This place gets clearer when people walk into it.
```

```text
Someone always brings the missing piece.
```

### Pattern 3: We Need A Thing

Use when the next step needs materials, tools, skills, or local knowledge.

Post types:

- Facebook local ask
- Instagram story
- GHL email segment if urgent

Opening lines:

```text
Quick local ask.
```

```text
We are looking for useful things, not fancy things.
```

```text
Before we buy new, we want to ask local.
```

### Pattern 4: We Learned Something

Use when the weekend changed the plan.

Post types:

- reflective Instagram caption
- newsletter lead
- founder note

Opening lines:

```text
We learned something useful this weekend.
```

```text
The plan changed a little after seeing people in the space.
```

```text
The idea got simpler once we stood in the room.
```

### Pattern 5: The Next Date

Use when there is a working bee, open day, gathering, or small invitation.

Post types:

- Facebook event post
- Instagram reminder reel
- newsletter CTA

Opening lines:

```text
Next chance to come through.
```

```text
We are opening the gate again.
```

```text
Come for an hour if you can.
```

## Video Edit Recipes

### Recipe 1: Before And After

Use when the site visibly changed.

```text
Length: 15 to 30 seconds
Template: Place Moment or Story
0-2s: after shot first
2-5s: before shot
5-15s: work happening
15-25s: details
25-30s: ask or next step
Overlay: Small progress this weekend
```

### Recipe 2: One Human Moment

Use when someone did or said something that carries the story.

```text
Length: 20 to 45 seconds
Template: Story
0-3s: person or action first
3-10s: context
10-25s: the useful detail
25-40s: why it matters
40-45s: invitation
Overlay: The best part was who showed up
```

### Recipe 3: Walk The Space

Use when you have mixed clips but no one clean story.

```text
Length: 30 to 45 seconds
Template: Walkthrough
0-4s: entry
4-15s: garden
15-28s: kitchen
28-38s: art space
38-45s: next step
Overlay: Garden. Kitchen. Art Space.
```

### Recipe 4: The Ask

Use when you need help.

```text
Length: 15 to 25 seconds
Template: Place Moment
0-3s: show the place
3-10s: show the gap
10-20s: show the list
20-25s: message us
Overlay: Quick local ask
```

## Example Agent Output

If Ben says:

```text
Weekend debrief. We cleared some of the garden path, found a bunch of old pots, Nic was talking about the long table again, kids were running around the shed, and the milk crate art got people talking. We need chairs, shade cloth, and someone who knows native propagation.
```

The agent should produce:

```text
The center of the week is: the place got more understandable once people moved through it.

What to publish:
1. The path opened - Instagram reel - show progress.
2. Quick local ask - Facebook - chairs, shade cloth, native propagation.
3. The long table keeps coming back - Instagram/Facebook - explain the kitchen starting point.

Video to make first:
30 second walkthrough: garden path -> old pots -> shed/kids -> long table detail.

One thing to avoid:
Do not make it sound like the garden plan is fixed. Ask for input.
```

Then write the actual captions.
