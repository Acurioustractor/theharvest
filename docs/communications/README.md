## Weekly Flow

1. Capture raw notes in [[THIS-WEEK|This Week]].
2. Pull useful WhatsApp moments from [[debriefs/README|Debriefs]].
3. Shape the week in [[weekly-plans/README|Weekly Plans]].
4. Build and schedule posts in GHL.
5. Send the newsletter in GHL.
6. Pull published GHL records back into Notion.
7. Review what worked next Monday.
