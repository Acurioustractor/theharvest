**Be ready with:**
- Address: 9 Gumland Drive, Witta QLD 4552
- Postcode confirmation, lot number if asked
- Entity name: **The Harvest Pty Ltd** (in registration - confirm if asked)

**Success looks like:**

**Fallback if blocked:**
