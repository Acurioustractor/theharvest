## This Week's Main Idea

The Harvest is starting to make sense because people are shaping it physically.

The week should show:

- garden progress
- practical local asks
- milk crate pavilion progress
- one human moment from the actual week
- a short newsletter that asks for help

## Weekly Operating Loop

### 1. Capture

Sources:

- WhatsApp export
- phone photos and videos
- drone photos and videos
- notes from site
- comments and DMs
- GHL replies

Put raw material into Empathy Ledger first.

Use the Harvest tags:

- `milk-crate-pavilion`
- `the-garden`
- `the-cedar`
- `the-sauna`
- `the-shop`
- `make`, `grow`, `gather`, `eat`
- `before`, `during`, `after`, `milestone`
- `hero`, `featured`

Then reference the useful EL assets in:

- [[THIS-WEEK|This Week]], under `Inbox`
- the next weekly plan
- a WhatsApp debrief when the export is useful

### 2. Choose

Pick one center of the week.

Good centers:

- one corner changed
- someone showed up
- we need a thing
- the plan got simpler
- next chance to come through

### 3. Build

Build in this order:

1. Pick the EL media set.
2. First reel or carousel.
3. Facebook local ask.
4. Supporting Instagram or Facebook post.
5. Newsletter.

GHL is the publishing desk.

### 4. Publish

Publish or schedule in GHL.

Do not publish straight from WhatsApp or Obsidian.

### 5. Record

After publishing:

```bash
npm run sync:social -- --pull-ghl --apply
```

This pulls GHL records back to Notion.

### 6. Learn

On Monday, check:

- comments
- DMs
- practical offers
- newsletter replies
- what felt alive
- what to repeat

Record the answer in [[THIS-WEEK|This Week]] before starting the next plan.

## Key Rules

- One post, one job.
- GHL publishes.
- Empathy Ledger holds the media and story source.
- Notion records.
- Obsidian thinks.
- WhatsApp is raw material, not public copy.
- Ask permission before quoting people or using sensitive images.
- Use space, hands, materials, and progress before faces.
