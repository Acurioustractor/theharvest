## How to explain the design in plain words

The member system has internal vocabulary that must never reach a broad email.
Translate it.

| Internal | Say instead |
| --- | --- |
| `member-level:*` tags, four levels | Nothing. Describe what people do, not what tier they hold. |
| Pods (`pod:garden`, `pod:shop-makers`, `pod:events`) | Garden hands, shop makers, workshop and events people. |
| Mighty Networks, Spaces | "a small inside room we are testing with a few people first" |
| `platform:mighty-invited` | Nothing. An invite is a personal email. |
| Founding lifetime member | Not in any broadcast. Personal note first, public mention only with consent. |
| Future paid membership | One honest line at most. Free now. If that ever changes, hearing first stays. |

The one promise, repeated everywhere:

```text
For now, membership means hearing first, finding the next useful thing, and helping shape what The Harvest becomes.
```

Honesty guard: membership is not a discount card, a vote, or venue access.
Say the first one plainly in the email. Keep the rest off the page so nothing
reads as a retraction.

## Ways to keep it simple and clear

1. One promise, repeated: hear first, help shape. Everything else is detail.
2. Levels stay internal. Public words describe doing, not rank. The member
   system doc lists "levels feel like hierarchy" as a fail signal.
3. No tag names, no platform names in broad email. "Inside room", not Mighty.
4. Founding lifetime recognition is a personal note, never a broadcast. The
   cohort is not consent-checked yet, so no names or photos anywhere.
5. Free now, honest about later. If paid membership ever starts, it comes after
   the room proves value, and founding recognition stays. One line, no selling.
